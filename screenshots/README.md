# Screenshots Folder

This folder contains screenshots required for Strava production submission.

## Required Screenshots

1. **screenshot-consent-modal.png**
   - Consent modal that appears before OAuth
   - Shows privacy policy and terms acceptance

2. **screenshot-strava-authorize.png**
   - Strava's authorization page during OAuth
   - Shows requested scopes and permissions

3. **screenshot-post-auth-success.png**
   - Post-auth success/syncing state
   - Shows confirmation that Strava is connected

## Optional Screenshots

4. **screenshot-connect-button.png**
   - Setup page showing the "Connect with Strava" button
   - Optional but recommended

## How to Capture

See: [`docs/SCREENSHOT_STEP_BY_STEP_GUIDE.md`](../docs/SCREENSHOT_STEP_BY_STEP_GUIDE.md)

## Screenshot Requirements

- **Format:** PNG (preferred) or JPG
- **Resolution:** At least 1920x1080
- **Quality:** High quality, all text readable
- **File Size:** Under 5MB per screenshot
